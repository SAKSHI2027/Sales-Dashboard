# Sales-Dashboard
I developed an E-commerce Sales Dashboard in Power BI to analyze sales, profit, quantity, customers, payment modes, categories, and state-wise performance. I used Power Query for data cleaning and transformation and DAX for calculations, creating interactive visualizations and filters to identify key business insights.


#📊 MADAV E-Commerce Sales Dashboard

An interactive E-Commerce Sales Dashboard developed using Power BI to analyze sales performance, profitability, quantity, customer behavior, payment methods, and product categories.

🔍 Key Features
KPI Cards displaying:
Total Sales Amount: 438K
Total Profit: 37K
Average Order Value (AOV): 121K
Total Quantity: 5,615
Quarter-wise filtering from Qtr 1 to Qtr 4.
State-wise sales analysis to compare performance across different states.
Monthly profit analysis to identify profitable and loss-making months.
Payment mode analysis using a donut chart for COD, UPI, Debit Card, Credit Card, and EMI.
Category-wise quantity analysis for Clothing, Electronics, and Furniture.
Sub-category analysis for products such as Printers, Bookcases, Sarees, Accessories, and Tables.
Customer-wise sales analysis to identify high-value customers.
🛠️ Tools & Technologies
Power BI
Power Query
DAX
Data Cleaning & Transformation
Data Visualization
Interactive Dashboard Design
🎯 Objective

The objective of this dashboard is to transform raw e-commerce sales data into meaningful visual insights that can help understand sales trends, profitability, customer performance, payment preferences, and product demand.
